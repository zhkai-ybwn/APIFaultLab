# APIFaultLab 隐私说明

简体中文 · [English](PRIVACY.md)

APIFaultLab 在用户接入的开发网页上读取接口方法、地址、页面路由和请求结果，用于发现接口、按条件匹配规则和显示命中。匹配查询参数、请求头或 JSON 条件时，插件仅在当前网页中读取满足候选范围的必要字段。采样功能仅在用户启动后读取对应的真实响应。

保存的方案、接口目录、忽略规则、站点页面归组设置和自定义场景保存在当前 Chrome 配置的扩展本地存储中。运行规则和请求摘要使用 Chrome 扩展会话存储。首屏保护在测试网页的会话存储中保存随机会话标记。规则和响应正文由扩展会话管理。

插件没有远程数据服务，也不包含任何统计分析、遥测上报或第三方数据共享。用户可以主动下载备份、方案或诊断文件。完整备份和用户主动导入的文档示例可能包含页面地址、响应正文和匹配条件，分享前请检查。Agent Skill 生成接口目录时，请根据所选 Agent 工具的数据处理方式决定可以提供哪些资料。

用户可以在工作台管理已保存的配置，或在 Chrome 扩展管理页调整站点访问权限。卸载扩展会移除其本地存储，已经下载的文件由用户自行管理。
