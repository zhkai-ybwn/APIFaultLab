# 界面与交互设计

**APIFaultLab · 工具栏弹窗与 DevTools 工作台 · v0.4 · 2026-11-23**\
配套文档 [接口异常测试插件需求设计](接口异常测试插件需求设计.md) · [技术选型与架构设计](技术选型与架构设计.md)

## 1. 两个入口

| 入口 | 当前任务 | 布局 |
| --- | --- | --- |
| Chrome 工具栏弹窗 | 核对当前站点与运行状态，开关采集或停止模拟 | 一个紧凑的控制面板。顶部显示 APIFaultLab、站点和状态。采集用开关，运行中的模拟提供独立的停止动作。底部用 `F12` 和 **APIFaultLab** 提示工作台位置。 |
| F12 的 APIFaultLab 标签页 | 查接口、配置模拟、批量应用、导入文档、保存和启用方案 | 顶部显示被检查页面与状态。宽窗口使用接口表与检查区，窄窗口允许检查区折回列表内。操作集中在工作条，按需展开方案和编辑区。 |

弹窗操作当前浏览器活动标签页。工作台绑定创建该 DevTools 的被检查标签页，即使用户切到别的 Chrome 窗口，也保留正确目标。两个入口共享同一份会话状态。

## 2. 视觉与操作反馈

- 系统字体承载中文和操作文案，接口方法、路径、条件与状态码用等宽字体。两个入口共享浅色与深色语义样式。DevTools 工作台匹配 DevTools 主题。
- 主界面用通栏、细分隔线和表格。单一强调色用于活动选择、确认按钮和可交互链接。颜色结合文字或符号表达采集、命中、等待和出错。
- 按下即有短促可见反馈。轻微的过渡仅用于选择和按钮反馈。允许随时关闭编辑或切到另一行。尊重减少动态效果设置，键盘可达，焦点保持可见。
- 控件靠近作用对象。行勾选产生批量操作，选中接口可以检查最近请求与生效的场景。导入文档和检查响应都在当前工作台内完成。

## 3. 接口发现与配置

1. 从 F12 进入后自动识别被检查标签页的 URL。需要当前站点访问权限时显示「授权此站点」，用户可由此授予单站点权限。
2. 同一页面 URL 的请求用一个组。切换到新 URL 加载相应接口。完成较晚的请求仍记在发起时所属组。列表包含方法、接口、格式或来源和当前命中情况。用户可按方法或路径筛选。
3. 点接口的「模拟」，选择 404、空列表、慢响应或其他场景。共用 POST 地址可以在同一接口配置多条互斥的条件规则，例如 `/operationName` 等于 `ListOrders`。请求详情、模拟条件和响应编辑在检查区就近阅读。
4. 勾选多个接口，打开「批量设置」。逐项预览会受影响的规则，校验通过后一起应用。未提交的编辑按页面 URL 保存为界面草稿。

搜索下方提供业务、静态、地图、有规则和已忽略的快速分类。选择可见接口后，底部可「忽略所选」或进入批量设置。筛选外的选择单独标记。路径前缀从「忽略规则」添加，预览当前匹配数。可从规则区撤销，也可在「已忽略」恢复单独忽略的接口。

## 4. 导入文档、响应和方案

- **导入文档** 打开本地 OpenAPI 或 Swagger JSON/YAML 文件。预览路径、操作名和响应来源，按需覆盖当前环境的实际 API 地址。确认后将选中接口加入当前页面。文档导入但尚未触发的接口显示独立状态，真实请求出现后合并。
- **响应** 预览状态码、媒体类型、延迟和正文。空列表可将业务结构内的数组清空，同时把指定总数字段置零。已有真实样本时显示来源。样本不可用时提供文档示例和手写响应。
- **场景** 单条与批量使用同一个按类别分组的场景选择器。可在编辑器保存当前响应，或从请求列表的「场景」进入场景库管理。选择预设会填入编辑内容。详情顶部持续显示应用按钮和范围摘要，点击按钮即可提交。
- **方案** 保存用户确认过的合成正文、匹配条件、前置状态、触发步骤与预期表现。加载后先预览再启用。运行规则和方案保存分别处理。

## 5. 刷新、停用和恢复

| 状态 | 反馈与动作 |
| --- | --- |
| 同标签页、同站点刷新 | 规则列表保留。新文档尚未确认时显示「正在恢复规则」，确认后显示运行数量，新一轮命中重新统计。 |
| 恢复未确认 | 显示失败原因和重新接入入口，可从工作台或弹窗停止该标签页的规则。 |
| 当前规则已生效，尚未触发 | 显示等待请求。用户从被测页面触发查询或表单。 |
| 本轮命中或放行 | 显示模拟状态、失败、延迟或「请求已放行」，供用户与真实页面表现对照。 |
| 停止中或停止未确认 | 保持清晰的占位状态，允许再次停止或重连。 |
| 停止后收到真实请求 | 先显示等待页面重新请求，捕获目标接口的真实响应后提示用户核对页面恢复。 |

关闭弹窗或 DevTools 不重置规则。跨源导航、关闭测试标签页或浏览器重启结束运行会话。已保存方案保留在本地。工作台刷新与被检查页面刷新分别处理，样本只在会话内临时保留。
