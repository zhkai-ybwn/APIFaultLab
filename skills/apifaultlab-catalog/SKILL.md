# 生成 APIFaultLab 接口目录

1. 确认 APIFaultLab 当前页面的完整 URL，以及用户要整理的接口范围。可以从本地源码、接口文档或用户提供的请求记录提取证据。浏览器采集需要当前会话有相应授权。
2. 从调用点记录 HTTP 方法、来源和路径。对多个操作共用的 POST，优先查找可证明的分流字段，例如经源码或请求记录确认的 `operationName`。找不到可靠的字段和值时，保留空条件并说明。
3. 按[接口目录格式](references/接口目录格式.md)生成本地 JSON。根据来源标记实际记录、文档声明或推断。仅保留可共享的元数据，省略认证信息、真实请求或响应正文及不必要的地址参数。
4. 把 JSON 文件交给用户，在对应页面的 F12 APIFaultLab「导入」面板确认。用户可从目录操作创建规则草稿，检查范围后手动启用。

同一接口的多个操作可以参考[共用请求示例](references/共用请求目录.json)。只有确认了服务来源才能生成条目。遇到代理前缀、环境来源或路由归属无法从证据确定时，列出缺少的信息。
